Week 2: SQL Functions and Clauses 📊

During my second week of learning Data Analytics at AppClick ICT Academy, I explored several SQL functions, clauses, and operators. These concepts help me retrieve, filter, organise, and analyse data in a database.

1. Aggregate Functions

Aggregate functions perform calculations on a set of values and return a single result.

The aggregate functions I learned include:

- COUNT(): Counts the number of records or values.
- SUM(): Calculates the total of numeric values.
- MIN(): Returns the smallest value.
- MAX(): Returns the largest value.
- AVG(): Calculates the average of numeric values.

2. SQL Clauses

I learned about different SQL clauses and how they help structure queries.

- FROM: Specifies the table from which data is retrieved.
- WHERE: Filters records based on specified conditions.
- ORDER BY: Sorts query results.
- GROUP BY: Groups records that share the same values in specified columns.
- LIMIT: Restricts the number of rows returned.
- HAVING: Filters groups based on specified conditions, often when aggregate functions are used.

3. Text Functions

Text functions help manipulate and work with character strings.

The functions I learned include:

- UPPER(): Converts text to uppercase.
- LOWER(): Converts text to lowercase.
- TRIM(): Removes leading and trailing spaces from text.
- CONCAT(): Combines two or more strings into one.

4. Date Functions

Date functions help extract information from dates and work with date values.

The functions I learned include:

- DAY(): Extracts the day of the month from a date.
- MONTH(): Extracts the month number from a date.
- YEAR(): Extracts the year from a date.
- MONTHNAME(): Returns the name of the month.
- DAYNAME(): Returns the name of the day of the week.

5. Operators Used with the WHERE Clause

I learned about operators that help specify conditions when filtering records.

These include:

- IN: Checks whether a value matches any value in a specified list.
- AND: Requires all specified conditions to be true.
- OR: Requires at least one of the specified conditions to be true.

These operators help make SQL queries more flexible when selecting specific records.

6. My Key Takeaway

My second week of learning SQL expanded my understanding beyond creating databases and inserting records. I learned how to summarise data using aggregate functions, organise queries using SQL clauses, manipulate text, work with dates, and apply conditions when filtering records.
