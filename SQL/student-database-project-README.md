Student Database Management System

Project Overview

This project involves creating a simple Student Database Management System using SQL. It demonstrates how to create a database, design a table, and insert student records.

Project Objectives

- Create a database for storing student information.
- Create a table to organize student records.
- Insert student data into the table.
- Practise basic SQL database management operations.

Tools Used

- MySQL
- MySQL Workbench

Tasks Performed

- Created a student database.
- Created a "students" table.
- Inserted five student records.
- Practised writing and executing SQL queries.

What I Learned

Through this project, I practised SQL database creation, table creation, data insertion, and basic database management.
